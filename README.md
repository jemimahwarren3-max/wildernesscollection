# The Wilderness Collection

A portfolio demonstration site for **The Wilderness Collection** — a fictional luxury African safari, lodge and destination brand. Built with Next.js (App Router), TypeScript, Tailwind CSS v4 and Motion.

All lodges, rates, guest stories and journal articles are fictional sample content. Destination information (Zimbabwe, Botswana, Zambia, South Africa, Tanzania) is general and real; photography and video are sourced from Pexels under its free-to-use licence.

## Highlights

- Cinematic scroll-driven video entrance on the homepage
- Shared `PageHero` pattern (parallax video/image, kinetic word-reveal headlines) across every interior page
- Destinations, lodges, experiences and journal — each with a listing page and statically generated detail pages
- A working journey-planning enquiry form (client-side validation, mock submission with a generated reference number — no backend wired up)
- Custom 404 page and favicon/brand mark

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

- Next.js 16 (App Router, Turbopack)
- TypeScript
- Tailwind CSS v4
- Motion (`motion/react`) for animation
